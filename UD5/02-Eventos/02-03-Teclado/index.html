UD4.-Interacción con el usuario. Eventos y formularios

02-03- Teclado

Formulario

Abre la consola. Escribe, mantén una tecla pulsada, prueba Shift, las flechas y pegar con el menú contextual. Alt + flecha arriba selecciona el texto del campo.

Este campo permite escribir o pegar cualquier texto, pero al enviar solo acepta dígitos del 0 al 9, o quedar vacío.
